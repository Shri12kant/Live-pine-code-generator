# 📍 Live Indian Area & City PIN Code Finder

A fast, modern, and responsive React frontend application to find official postal PIN codes for any city, locality, or area across India. Powered by India Post API and OpenStreetMap reverse geocoding for live GPS-based location detection.

---

## ✨ Features

- 🔍 **Area & City Search**: Search any Indian city, suburb, or colony name (e.g. *Bandra*, *Connaught Place*, *Whitefield*, *Indore*, *Patna*) to retrieve official 6-digit postal PIN codes and branch details.
- 🔢 **PIN Code Lookup**: Enter any 6-digit PIN code to view all registered post offices and delivery coverage areas.
- 📍 **Auto-Detect My Location**: 1-click GPS detection to automatically find your current area and PIN code.
- 📋 **1-Click Copy**: Copy PIN code directly to clipboard with instant toast notifications.
- 🗺️ **Google Maps Integration**: Direct links to open each post office/area in Google Maps.
- 🎯 **Advanced Filters**: Filter results by State, District, and Delivery Status.
- ⚡ **Popular Cities Quick Chips**: Fast access to major Indian cities.
- 💾 **Bookmarks & History**: Save favorite PIN codes and view recent search history locally in your browser.
- 🌓 **Dark & Light Mode**: Smooth theme toggling with system preference detection.

---

## 🚀 Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **APIs (100% Free, Client-side)**:
  - India Post Office Directory API
  - OpenStreetMap Nominatim Reverse Geocoding

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Shri12kant/Live-pine-code-generator.git
cd Live-pine-code-generator
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
